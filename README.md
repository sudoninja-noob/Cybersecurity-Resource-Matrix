## What is this?

A **zero-dependency cybersecurity knowledge base** with two modes:

| Mode | How |
|------|-----|
| 🖥️ **GUI** | Open `index.html` in a browser — full sidebar navigation, searchable, section tabs, one-click `.md` download |
| 📄 **Markdown** | Browse the `domains/` folder — 46 standalone `.md` files, one per domain, readable anywhere |

**46 domains × 27 sections × 1,474 curated links** — sourced from standards, open-source tools, official docs, labs, certifications and research papers.

---

## 🖥️ GUI Features

- **Sidebar** — all 46 domains grouped by category, with search (⌘K)
- **Domain view** — large header, intro, every section rendered with tables, links, code blocks
- **Section tabs** — jump to any of 27 sections instantly, tab highlights as you scroll
- **⬇ Download .md** — one click to get the standalone markdown file for any domain
- **Hash routing** — `#domain=5` opens Cloud Security directly, shareable links
- **Keyboard shortcuts** — ⌘K to search, Esc to go home
- **Mobile responsive** — sidebar drawer on mobile
- **Zero dependencies** — one HTML file + one data JS file + 46 MD files
