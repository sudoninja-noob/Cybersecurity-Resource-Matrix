## Section 26: Latest Developments <a name="section-26"></a>

Focus areas include privacy, LE Audio, Mesh, secure provisioning and implementation-specific stack security. NIST’s Bluetooth guidance remains useful but covers Bluetooth only through 4.2, so it should be supplemented with current Bluetooth SIG material. ( [NIST Computer Security Resource Center](https://csrc.nist.gov/pubs/sp/800/121/r2/upd1/final))
