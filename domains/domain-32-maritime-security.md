- ⭐⭐⭐ [IMO Maritime Cyber Risk](https://www.imo.org/en/ourwork/security/pages/cyber-security.aspx)⭐⭐⭐ IACS UR E26/E27 ⭐⭐⭐ IEC 62443 for onboard OT ⭐⭐ BIMCO maritime cyber guidance IMO defines maritime cyber risk around technology compromise causing operational, safety or security failures and now lists revised cyber-risk-management guidance. ## Section 03: Standards / Compliance <a name="section-03"></a>

- ⭐⭐⭐ IMO MSC-FAL.1/Circ.3 revisions 
- ⭐⭐⭐ IACS UR E26 — Cyber Resilience of Ships 
- ⭐⭐⭐ IACS UR E27 — On-board systems/equipment IMO ISM Code 
ISPS Code 
IEC 62443 
IEC 61162/NMEA 
ISO 27001 
IACS E26 and E27 introduced cyber-resilience requirements for new ships and onboard systems/equipment and have applied to covered new ships since 2024. ( [IACS](https://iacs.org.uk/news/iacs-ur-e26-and-e27-press-release))
